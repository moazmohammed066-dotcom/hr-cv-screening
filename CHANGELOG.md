# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-18

### Added
- FastAPI backend with REST API and static frontend hosting.
- AI pipeline: PDF extraction, LLM chunking and metadata extraction, embeddings, FAISS search.
- Candidate filtering by years of experience and skills.
- Job-description based ranking with score, summary, strengths and missing requirements.
- RAG chat over the uploaded CVs.
- Dashboard, shortlist workflow (New / Under Review / Shortlisted / Rejected), candidate comparison and deletion.
- Issue and pull request templates, Dockerfile.
